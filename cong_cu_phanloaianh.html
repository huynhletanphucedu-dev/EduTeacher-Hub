🗂️ Phân loại ảnh

Chọn thư mục chứa ảnh (ảnh hoạt động, ngoại khóa, sự kiện lớp…), tạo các thư mục con, bấm chọn ảnh rồi gán vào thư mục. Một ảnh có thể nằm trong nhiều thư mục. Ảnh không tải lên mạng – mọi thứ xử lý ngay trên máy.

Trình duyệt này chưa hỗ trợ. Thầy/cô hãy mở file bằng Google Chrome hoặc Microsoft Edge trên máy tính nhé.
🏠🗂️ Phân loại ảnh

Thư mục

Chọn ảnh ở bên phải, rồi bấm vào thư mục (hoặc phím số) để gán. Bấm lần nữa để gỡ ra.

Đang chọn

0 ảnh
1…9, 0 gán / gỡ thư mục tương ứng
←↑→↓ di chuyển ô vàng
Space chọn / bỏ chọn ảnh ở ô vàng
Shift + bấm: chọn cả dãy ảnh
Ctrl+A chọn tất cả · Esc bỏ chọn
Enter hoặc nhấp đúp: xem to từng tấm
U bật/tắt lọc “Chưa phân loại”
Tiến độ được tự lưu trên máy này.

Đang xuất ảnh…

Bấm thư mục hoặc phím số để gán / gỡ · ← → qua ảnh · U lọc chưa phân loại · Esc thoát
